## ⚡ EventScripts for Mac – Smart Event Automation

EventScripts is a Mac utility that watches for selected system and application events and launches scripts or applications when those events occur. It can execute **AppleScripts, Automator workflows, Perl scripts, shell scripts, and applications**, making it useful for building custom event-driven workflows.

### ✨ What EventScripts Can Do

* ⚡ **Event Triggers** → Run actions automatically when monitored events occur.
* 🍎 **AppleScript** → Execute AppleScripts from selected Mac events.
* 🤖 **Automator** → Launch Automator workflows automatically.
* 💻 **Shell Scripts** → Trigger shell-based automation.
